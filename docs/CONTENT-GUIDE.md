# 内容合规指南 · 宝盒比特币（CONTRIBUTING 的合规铁律版）

> 对应规划 `运营总体规划2.md` §1 与 `运营总体规划2.1-补强.md` §B。
> **任何内容发布前，必须走完「发布前 9 项自查」，否则不发。**

## 1. 各平台政策要点（速查）
- **抖音**：客观中立科普可发；禁「虚拟货币兑换/交易中介/定价」等非法金融内容、禁喊单荐股；建议财经资质认证。
- **视频号/公众号**：知识科普可发；禁诱导交易、收益承诺；币圈词易触发人工复核。
- **B站/YouTube/X**：最宽松，原理/历史/技术科普自由；X 最自由。

## 2. 敏感词 / 违规词自检工具（发布前必过）
每次发文/视频口播稿，先粘进工具检测，红色词改掉再发：
- **零克查词** lingkechaci.com / ci.lingke.pro（抖音·小红书·B站·快手，免费）
- **句易网** ju1.cn（含图片检测，图文封面也查，免费）
- **UU 在线工具** uutool.cn/word-dy（免登录快查，免费）

## 3. 发布前 9 项合规自查清单
```
[ ] 1. 零克查词 / 句易网 全文已过，无红色违规词
[ ] 2. 全文无「买/卖/涨/跌/现在能不能进/稳赚/收益」等引导交易表述
[ ] 3. 全文无价格预测、无荐标、无晒收益截图
[ ] 4. 已带风险提示（用下方固定文案，文末/视频尾板）
[ ] 5. AI 生成画面/视频已加 AIGC 标识
[ ] 6. 音乐来自无版权库（见「BGM 来源」），非随手抓的热歌
[ ] 7. 引用他人文章/数据已注明来源 + 外链，未整篇搬运
[ ] 8. 不使用「最/第一/唯一/国家级」等广告法极限词
[ ] 9. 标题无夸张诱导（如「一夜暴富」「必看」式）
```

## 4. 固定风险提示文案（每条必带）
- 图文/视频尾板：
  > 比特币价格波动剧烈，本文/本视频仅作区块链科普，不构成任何投资建议。投资需谨慎，盈亏自负。
- 重大事件文追加：以上为客观事实陈述，不构成任何市场判断或操作建议。

## 5. BGM / 无版权音乐来源
- 冷启动：剪映音乐（站内授权）+ YouTube Audio Library + Pixabay Music，全免费。
- 矩阵起量后：Artlist（$9.99/月）或 Epidemic Sound（$15/月）统一授权。
- 国内向精品：光厂 / 包图。
- ⚠️ 绝不用抖音/微信热门歌做商业化 BGM，必被下架/扣收益；下载授权文件备查。

## 6. 版权与署名
- 文章只摘要 + 外链原文，不整篇搬运。
- AI 视频标 AIGC；引用数据标注来源。
- 音乐用无版权库并保留许可证备查。
