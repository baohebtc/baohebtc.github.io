🎙️ Andreas Antonopoulos 集

他是把比特币讲清楚这件事上影响最大的人之一——不是靠预测行情，而是靠在讲台上一步步推导。《精通比特币》三个版本全部以 CC BY-SA 4.0 开放了全文，这在同类技术书里少见：意味着任何人都可以合法免费读全本，并可在注明出处的条件下再传播。本栏先把「能免费合法读全本」的书排在前面。

一、可以合法免费读全本的三本书
图书开源

《精通比特币》（Mastering Bitcoin）开源仓库

从交易结构、脚本、钱包到挖矿与共识，一本在手可以读到底。第三版把 covenants、Taproot 之类的新内容也补了进来。仓库里连图稿源文件都开放——这也是开源书的好处。

作者：Andreas M. Antonopoulos 来源：GitHub 官方组织仓库 ↗ 许可：CC BY-SA 4.0
在线阅读不用装环境

《精通比特币》在线免费阅读（含多语种）

不想翻 GitHub 的话，直接在这里读。站点提供多语种版本，中文战友也不用先啃英文——虽然本站仍建议有条件的读者对照英文原文看技术细节。

作者：Andreas M. Antonopoulos 来源：bitcoinbook.info 官方免费版 ↗ 许可：CC BY-SA 4.0
镜像备用

《精通比特币》作者镜像仓库

第三版的作者个人镜像，与主仓库内容一致。当官方仓库在处理较多议题、想直接看作者分支的更新时比较好用。

作者：Andreas M. Antonopoulos 来源：作者 GitHub 仓库 ↗ 许可：CC BY-SA 4.0
图书开源

《精通闪电网络》（Mastering the Lightning Network）

讲比特币的第二层：支付通道、路由、洋葱路由、看门塔。书的内容偏工程实现，读之前建议先把主链那本书的「交易与脚本」部分过一遍。

作者：Andreas M. Antonopoulos 等 来源：GitHub 官方组织仓库 ↗ 许可：CC BY-SA 4.0
图书开源

《精通以太坊》（Mastering Ethereum）

本站聚焦比特币，但把这本列进来有理由：读完它需要再回头看比特币，会清楚看出「世界计算机」与「点对点电子现金」在设计取舍上的根本分歧在哪里。

作者：Andreas M. Antonopoulos、Gavin Wood 来源：GitHub 官方组织仓库 ↗ 许可：CC BY-SA 4.0
二、动手用的教学示例
示例可跑起来

比特币支付的 Wi-Fi 门户（教学 Demo）

一个能用比特币付费解锁上网的 Wi-Fi 强制门户。代码很短，目的是让人看清「一次链上支付如何驱动一个真实的物理入口」——比读描述直观得多。

作者：Andreas M. Antonopoulos 来源：GitHub 仓库 ↗ 许可：开源（MIT）
示例入门友好

HD 钱包生成教学实现

用 Python 演示分层确定性钱包是怎么从一颗种子长出无数地址的。想理解助记词与派生路径，看这个比对读规范条款快。

作者：Andreas M. Antonopoulos 来源：GitHub 仓库 ↗ 许可：开源（MIT）
