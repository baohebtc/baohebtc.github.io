# Phase 4 修正版：安全区裁切 + 无 inpaint 方案

**日期**：2026-09-04
**触发**：v4 inpaint 留下肉眼可见硬贴痕迹（用户原话："去水印简直无法直视"）
**核心**：母图保持原样，9 站从**无水印安全区**各自裁出横条缩放为封面

## 1. 为什么做

### 1.1 v4 方案为什么失败（硬证据）

v4 `remove_wm_v4.py` 用「整片纹理替换」——从水印区正上方 700px 取同宽纹理 blit 覆盖水印区。理论上"纹理延续"，实际留下肉眼可见硬贴痕迹：

- **色温/光照不一致**：原图是水彩画，被贴入的是高清晰度"实景风"树木（看 ev-nowm.png 一眼可见）
- **笔触不一致**：水彩的笔触在边界处突然被实景风"硬切"
- **背景逻辑断裂**：原图水印区上方是"村舍+草坡"，被贴的是"密林"，逻辑上说不通

**用户原话**："去水印简直无法直视，完全无法用。"

### 1.2 正确思路

**完全不要 inpaint**。水印位于母图右下角 (x: 1232-1704, y: 2012-2312)。封面是 2.35:1 的横裁，**如果裁切范围从不越过 y=2012，水印根本进不了画布**。

母图 1760×2368，安全区 = 1760×2012（顶部 85%）。
封面 900×383，从安全区取 1760×749 缩放即得。安全区足够放下 1 张封面。
9 站取 9 个不同 y 中心，**天然区分**——每张都展示该站地标。

## 3. 检验标准

### 3.1 L1 机器检验（每张必须 ALL PASS）

| 项 | 阈值 | 改动说明 |
|---|---|---|
| 画布尺寸 900×383 | == | 不变 |
| 左上 ₿ PNG 已贴 | unique ≥ 30 | 不变 |
| 中央文字密度 | ≥ 2.8% | 不变（水彩底已放宽） |
| **水印区零像素** | 0 像素与水印色簇匹配 | **新增**：扫描右下 16%×8% 区域，检测是否含有水印特征色 |
| **右下角纹理连贯** | 与左上角色差 < Δ 阈值 | **新增**：保证不是"贴片"风格 |
| 缩略图可读 | ≥ 1% | 不变 |
| 底部无重文字 | < 4% | 不变 |
| 合规词 | 0 | 不变 |

### 3.2 视觉验证

- 整图缩略（200×85）肉眼过——9 站风格统一、有区分
- 右下角 16%×8% 裁出 3x 放大——零水印、零拼接痕
- 每张封面与站名对应（核对地标是否对位）

### 3.3 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 安全区内某站地标不清晰 | 站识别度低 | 已按地标分布精调 y_center（站1/1.5/4 都对位海湾+河流通段） |
| 缩略图可读度下降 | 列表视图模糊 | 文字位置/字号不变，只换底图 |
| 不同 y 裁切导致 9 站色调略不同 | 风格不统一 | 全部从同一张母图裁，相邻 y_center 间隔 100-300 px，色调在暖色主导 80.5% 范围内 |
| v2-B-01 原图丢失 | 切错无法回退 | 原图 v2-B-01.png 已保留，未动 |

## 5. 与 v4 方案对比

| 维度 | v4 (inpaint) | v5 (裁切规避) |
|---|---|---|
| 母图修改 | 有（右下 1232×300 区域被替换） | 无 |
| 痕迹 | 硬贴（清晰度/笔触/光照不一致） | 无（未进画布） |
| 算法复杂度 | 纹理匹配 + 高斯羽化 | 简单矩形裁切 |
| 可靠性 | 低（依赖纹理相似性） | 高（数学保证不进入） |
| 9 站区分度 | (nx,ny) 裁切同一母图 | y_center 各自不同 |
