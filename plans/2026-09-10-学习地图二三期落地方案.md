## 一、Why —— 先讲清楚为什么做

动手前我做了一轮 grill，发现三个真问题，都不是"锦上添花"，是"不做就一直是错的"：

### 问题 1（最严重）：网站标签违反刚拍板的规则，且与母图对不上

- 用户 2026-09-10 拍板：**站名不得出现在站号圆点的下方**。
- 但 `learning-map.html` 里 10 个 `name-box` **全部在圆点下方**（一期止血时沿用的是旧布局，只补了"可见性"，没动方向）。
- 母图 PNG 的新布局是 **上 8 / 左 2 / 下 0**。
- 结果：**同一张学习地图，网站版和图片版是两套长相，且网站版是违规的那套**。

### 问题 2：网站标签是"现代深色 UI"，与古地图母图违和

- 现状 `.nb-bg { fill: rgba(13,13,13,0.9) }` —— 深色半透明 + 彩色描边，是深色仪表盘语言。
- 母图是藏宝图/羊皮纸风，用户已选 **A 羊皮纸牌**（米色底 + 深棕边 + 深棕字）。
- 结果：**深浅两套语言打架**，标签像贴错了画布。

### 问题 3（价值层）：地图"能看"但"不好用"

- 底图 2.1MB 单档，移动端首屏硬扛。
- 10 站**没有已读状态** —— 用户学完三站回来，看不出自己学到哪，地图只是张漂亮图。
- **首页正文没有地图入口**（Python 复核：`index.html` 里 7 处"地图"全是标题/nav/footer/SEO，正文区 0 处）—— 全站最有辨识度的资产被藏起来了。

### 一句话结论

> 前两轮我们把"图"做对了，但"网站"还停在旧版；这次要把图和网站**收敛成同一套**，再补上让它从"能看"变"好用"的三件事。

## 三、How —— 三个关键决策

### 决策 1：网站**不**把标签烧进底图，保持"无标签底图 + SVG 标签层"

| | 烧进 PNG | SVG 标签层（选这个） |
|---|---|---|
| 小屏 375px | 字随图缩到 8px，糊 | 可整体隐藏，交给下方卡片 |
| hover 反馈 | 无 | 可放大/发光 |
| 中英双语 | 得烧两张图 | 一份 SVG 切文本 |
| 已读进度 | 做不了 | 可打勾/变色 |

**带标签 PNG 仍要出**，但它的用途是"图片产品"——公众号配图、视频片头尾、社媒分享卡。两条链路共用同一份坐标 JSON，保证长相一致。

### 决策 2：单一真相源 `map-stations.json`

上次的翻车点就是"图上改了、代码没改"。这次把坐标/方向/轴移/配色/链接全部收进一份 JSON：

```
map-stations.json ─┬─> gen_map_markers.py  → 生成网站 SVG 片段
                   ├─> make_label_variants.py → 生成 PNG 标签
                   └─> map-label-check.mjs → 校验两者一致（L8）
```

任何一处坐标变动，必须改 JSON 再重新生成，不允许手改产物。

### 决策 3：TDD 先亮红灯，再改代码

新建闸 `tools/dev/map-label-check.mjs`，先对着**当前违规的页面**跑，必须红；改完再跑，必须绿。

| 编号 | 验收条款（读者视角，不是技术指标） |
|---|---|
| L1 | 10 个站名框**没有一个在圆点下方** |
| L2 | 10 站齐全，站号集合 = {1, 1.5, 2, 3, 4, 5, 6, 7, 8, 9} |
| L3 | 站名框不越出画布（1760×2368） |
| L4 | 站名框两两不重叠 |
| L5 | 站名框不压住任何站的圆点（含自身） |
| L6 | 站名框是羊皮纸牌风格（米色底 + 深棕边 + 深棕字） |
| L7 | 10 个跳转链接全部可达 |
| L8 | 网站 SVG 布局 == JSON 布局（坐标容差 1px） |
| L9 | 小屏 375px 无横向溢出 |

e2e 交由既有 `ci-run.mjs`（六闸）兜底，新增闸并入。

1. **建真相源**：从已验证的布局导出 `map-stations.json`

3. **改代码**：`learning-map.html` SVG 位置 + 羊皮纸牌样式
4. **转绿**：复跑检查，L1–L9 全绿
5. **出成品**：带标签 PNG 竖版 + 横版裁切
6. **三期**：srcset 多尺寸 + localStorage 已读进度 + 首页入口卡片
7. **e2e + 提交**：`ci-run.mjs` 全量 → commit
