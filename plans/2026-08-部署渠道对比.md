# 比特币学习地图 · 全渠道部署方式对比

> 本站点性质：**纯静态多页 HTML/CSS/JS，无构建步骤、使用相对路径**。
> 因此几乎所有「静态托管」都能零配置直接上传/推送，不需要 Node 构建、不需要框架。
> 部署时务必**连同 `shared/ learning/ tools/ reference/` 整体上传**，只传 `index.html` 会丢失样式与脚本。

## 〇、先说备案（中国大陆必读）

| 场景 | 是否需要 ICP 备案 |
|------|------------------|
| 用**中国大陆服务器**（腾讯云 CVM、阿里 ECS、国内 COS/OSS）+ 国内解析域名 | **需要** ICP 备案 |
| 用**境外服务**（GitHub Pages / Netlify / Vercel / Cloudflare Pages / Firebase） | **不需要**备案 |
| 用**腾讯云 CloudStudio / EdgeOne** 的默认二级域名 | 通常不需要（平台已备） |
| 用 `file://` 或局域网自测 | 不需要 |

> 备案是「域名 + 国内服务器」组合要求。如果你只想最快让朋友/粉丝访问、不介意境外节点，**Cloudflare Pages / CloudStudio / GitHub Pages** 都能免备案上线。

## 二、各渠道「需要什么 / 怎么操作」要点

### 1. GitHub Pages
- **需要**：GitHub 账号；把整个文件夹 `git push` 到仓库。
- **操作**：仓库 Settings → Pages → 选 `main` 分支 + 根目录 → 约 2 分钟上线 `https://用户名.github.io/bitcoin-learning-map`。
- **自定义域名**：仓库里加 `CNAME` 文件写域名，域名 DNS 指向 `用户名.github.io`。
- **注意**：本机当前**无 GitHub 凭证**（无 gh CLI / SSH key / credential helper），push 需你登录授权。

### 2. CloudStudio 静态托管（腾讯）
- **需要**：腾讯云账号（已登录即可）；我有 `cloudstudio-deploy` 能力可代你部署整个文件夹。
- **操作**：上传文件夹 → 自动分配 HTTPS 公网地址。
- **优点**：国内访问好、零 git 凭证、最省事。

### 3. Cloudflare Pages
- **需要**：Cloudflare 账号（免费）；可拖拽上传，或连 GitHub 自动构建。
- **操作**：Dashboard → Pages → 上传 `比特币学习地图` 文件夹 → 自动 HTTPS + 全球 CDN。
- **优点**：国内相对快（香港/日本节点）、免费额度大、免备案。

### 4–5. Netlify / Vercel
- **需要**：账号；拖拽或连 git。
- **操作**：拖文件夹到部署页面即可，自动给 `*.netlify.app` / `*.vercel.app` 域名。
- **优点**：开箱即用；**缺点**：国内访问一般。

### 6–9. 腾讯云 EdgeOne / COS+CDN、阿里云 OSS、七牛/又拍/华为
- **需要**：对应云账号；**国内域名通常需 ICP 备案**；对象存储桶 + 开启「静态网站托管」+ 绑 CDN + 配 SSL。
- **优点**：国内极速、稳定、可控；**缺点**：配置步骤多、需备案。

### 10. Nginx 自建（CVM/ECS）
- **需要**：云服务器 + 域名 + SSL 证书 + **备案**。
- **操作**：`scp` 文件夹到 `/var/www/html/btc-map/` → Nginx `root` 指向该目录 → `try_files $uri $uri/ =404;` → 配 HTTPS。
- **优点**：完全自主；**缺点**：运维/备案成本最高。

### 11–12. 本地 / 局域网 / 开发者平台
- 仅自测或内部使用，不对外。

### 13. IMA / Notion / 飞书 内嵌
- 非公网部署，仅内部浏览/分享，无 SEO。

## 三、我的建议（结合你的情况：贵阳、面向国内粉丝/自媒体）

| 你的目标 | 推荐 |
|----------|------|
| 最快上线、零配置、国内也能开 | **CloudStudio**（我可代部署）或 **Cloudflare Pages** |
| 永久免费、自定义域名、长期维护 | **GitHub Pages**（需你提供仓库/授权） |
| 国内极速、不怕配置、有腾讯云 | **COS + CDN** 或 **EdgeOne Pages**（需备案域名） |
| 只是先自测 | 本地 `python3 -m http.server` |

> 一句话：**想省事选 CloudStudio；想永久免费自定义域名选 GitHub Pages；想国内极速选 COS+CDN（要备案）。**
